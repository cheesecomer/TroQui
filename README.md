# TroQui 🚃❓

トロッコに乗った女の子と一緒に進む、幼児向け知育クイズゲームです。

スマートフォンを左右に傾けて回答しながら、どこまで進めるかに挑戦します。

## 特徴

- スマホを傾けて回答する直感的な操作
- ひらがな・数・計算を楽しく学べる
- 問題が進むごとに制限時間が短くなる
- ライフがなくなるまで遊べるアーケードスタイル
- ドット絵風のかわいい世界観

## 現在実装済みのクイズ

### Addition

かんたんな足し算問題

```text
2 + 3 は？
```

### KanaFill

ひらがなの穴埋め問題

```text
あ ○ う
```

### GuessNumber

表示されたイラストの数を数える問題

```text
🍎🍎🍎🍎🍎

なんこある？
```

### KanaChoice

イラストの名前を当てる問題

```text
🐰

○さぎ
```

## ゲームルール

- 左右に表示された選択肢から正解だと思う方向を選ぶ
- 制限時間終了時点で選択中の回答が確定
- 不正解でライフを失う
- ライフが0になるとゲームオーバー
- スコアは到達した問題数

### 制限時間

| 到達問題数 | 制限時間 |
| ---------- | -------- |
| 1〜4問目   | 10秒     |
| 5〜9問目   | 8秒      |
| 10問目以降 | 5秒      |
